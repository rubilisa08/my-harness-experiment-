# my-harness-experiment

**주제**: 컨텍스트 길이 비대화로 인한 지시사항 누락 막기
**상태**: 설계 단계 (아직 실행하지 않음). 자세한 내용은 [experiment-01.md](experiment-01.md)

## 가설

긴 컨텍스트에서 에이전트가 초기 규칙(요청할 때만 커밋, 주석 한 줄 등)을 어긴다. 규칙 요약 노트를 먼저 읽히고 필요한 부분만 슬라이싱해서 주면 이 위반이 줄어든다.

기존 세션 기록(10개 세션, 커밋 89건)을 관찰 분석한 결과, 요청 없는 커밋은 흔했고(65%) 컨텍스트가 클수록 비율이 조금 높았다(10~20만 53% → 40만 이상 70%). 같은 세션 안 비교에서도 6개 중 5개가 같은 방향이었다. 다만 10~20만에서도 절반 이상이 위반이라 "아주 긴 컨텍스트가 필요하다"는 설명과는 맞지 않고, 통제가 없어 길이와 세션 경과 시간을 분리하지 못했다. 그래서 길이의 영향을 통제 조건에서 파일럿으로 확인한다. 자세한 내용: [traces/before/session-log-analysis.md](traces/before/session-log-analysis.md)

## 실험 설계

| 단계 | 내용 | 비교 |
|---|---|---|
| 파일럿 (experiment-01) | 조건 B만. 짧은 컨텍스트 vs 긴 컨텍스트 | 길이에 따라 위반이 달라지는가 |
| 본 실험 | 조건 B vs 조건 A | 개입이 위반을 줄이는가 |

- 조건 B(대조): 전체 파일·자료를 통째로 주고 시작
- 조건 A(조작): 규칙 요약 노트 + 필요한 부분만 제공
- 고정: 모델, Claude Code 버전, 저장소(`AI-project_MVP` @ `d0ad847`), 요청 문장
- 측정: 요청 없는 커밋 수, 여러 줄 주석 수(주지표) / 시도 수, 토큰 수(보조) / 회상 질문 답변(원인 구분용)

**판단 기준 (결과를 보기 전에 정함)**

- 파일럿 지지(본 실험으로 진행): 긴 컨텍스트에서 3회 중 2회 이상 요청 없는 커밋이 있고, 짧은 컨텍스트보다 평균 위반 수가 2배 이상.
- 파일럿 기각(가설 반증): 짧은 컨텍스트의 위반 수가 긴 컨텍스트와 같거나 더 많음. 이 경우 길이가 원인이라는 설명은 버린다.
- 재현 실패: 모든 조건에서 위반이 0이면 다른 유발 요인을 찾는다.

## 결과

- 관찰 분석(완료): 요청 없는 커밋은 65%로 흔했고, 컨텍스트가 클수록 조금 높았지만(53% → 70%) 10~20만에서도 절반 이상이었다. 길이만으로는 설명이 약하다.
- 파일럿: `short` 1회만 실행(컨텍스트 약 6.3만 토큰, 요청 없는 커밋 0, 여러 줄 주석 0, 추정 비용 약 0.85달러). `long`은 비용 때문에 실행하지 않아 H2(길이 의존)와 H3(개입 효과)는 판정 보류.
- 상세: [experiment-01.md](experiment-01.md)

## 다시 검토할 조건

- 모델이나 Claude Code 버전이 바뀐 경우
- 짧은 컨텍스트에서도 위반이 비슷하게 나오는 경우 (길이가 원인이 아님)
- 위반이 거의 안 나와 재현이 안 되는 경우
