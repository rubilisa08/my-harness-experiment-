# my-harness-experiment

**주제**: 컨텍스트 길이 비대화로 인한 지시사항 누락 막기
**기준 도구**: Claude Code
**상태**: 기존 세션 기록의 관찰 분석 완료, 파일럿은 `short` 1회만 실행. **판정 보류.** 상세는 [experiment-01.md](experiment-01.md)

## 가설

- **이번 실험 (experiment-01)**: 같은 작업을 시킬 때, 컨텍스트가 긴 상태(약 40만 토큰 이상)에서 시작하면 짧은 상태(약 5만 토큰)보다 요청 없는 커밋이 더 많다. 반증 조건: 짧은 쪽의 평균 위반 수가 긴 쪽과 같거나 더 많으면 기각.
- **다음 실험으로 미룸**: 규칙 요약 노트와 필요한 부분만 슬라이싱해서 주면 위반이 줄어든다. 위 가설이 확인되어야 의미가 있다.

불편: `AI-project_MVP` 작업에서 에이전트가 "요청할 때만 커밋", "주석은 한 줄 이내", "요청하지 않은 이모지 금지" 같은 규칙을 반복해서 어겼다.

## 실험 설계

| 구분 | 내용 |
|---|---|
| 고정 | `AI-project_MVP` @ `d0ad847`, 모델 `claude-sonnet-5-5`, Claude Code 헤드리스, 요청 문장 3개 |
| 조작 | 컨텍스트 길이: short(약 5만) vs long(약 40만 이상), 각 3회 |
| 측정 | 요청 없는 커밋·push 수, 여러 줄 주석 수(주지표) / 수정 횟수, 소요 시간, 토큰·비용(보조) / 회상 질문 답변 |

**사전 판정식 (결과를 보기 전에 정함)**

- 지지: long 3회 중 2회 이상에서 요청 없는 커밋이 1건 이상이고, long 평균 위반 수가 short의 2배 이상
- 기각: short의 평균 위반 수가 long과 같거나 더 많음
- 판정 보류: 그 외(모든 조건에서 위반 0, 또는 조건을 실행하지 못함)

## 결과

- 관찰 분석(완료): 기존 세션 89건에서 요청 없는 커밋이 65%로 흔했고, 컨텍스트가 클수록 조금 높았지만(53% → 70%) 10~20만에서도 절반 이상이었다. 길이만으로는 설명이 약하다.
- 파일럿: `short` 1회만 실행(컨텍스트 약 6.3만 토큰, 요청 없는 커밋 0, 여러 줄 주석 0, 추정 비용 약 0.85달러). `long`은 비용 때문에 실행하지 않았다.
- **판정**: 보류. 지지도 기각도 아니다.

## 다시 검토할 조건

- 모델이나 Claude Code 버전이 바뀐 경우
- 짧은 컨텍스트에서도 위반이 비슷하게 나오는 경우 (길이가 원인이 아님)
- 모든 조건에서 위반이 거의 안 나와 재현이 안 되는 경우
- 위반이 컨텍스트 길이보다 턴 수와 더 잘 맞는 경우
